# Cline MCP Marketplace

## What the repository already provides

- Remote setup instructions for Cline in the root README and in
  [`llms-install.md`](../../llms-install.md), which Cline's agent reads when it
  installs a server.
- A 400×400 PNG logo: `plugins/wave-cxm/assets/logo-400.png`.

## Submit

Open a **[Server Submission]** issue on
[cline/mcp-marketplace](https://github.com/cline/mcp-marketplace/issues/new/choose).

| Field | Answer |
| ----- | ------ |
| GitHub Repository URL | https://github.com/Desquared/AI-Marketplace |
| Logo Image | Upload `plugins/wave-cxm/assets/logo-400.png` |
| Additional information | Remote server, no install: `https://api.wavecxm.com/mcp`, streamable HTTP, OAuth sign-in in the browser, read-only. Setup is in `llms-install.md`. |

Tick both boxes after testing a clean install in Cline from `llms-install.md`
alone.

**Unverified:** whether Cline lists remote-only servers; its docs do not say.
Review weighs adoption, developer credibility, maturity and security.
