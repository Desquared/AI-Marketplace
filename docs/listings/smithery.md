# Smithery

On 2026-10-31 Smithery, now part of Arcade, shut down its proxy, API, CLI and
SDKs. The smithery.ai directory remains as a non-proxied registry with a
curated set of verified servers that show their direct MCP URLs.

- **No file is needed in this repository.** The old `smithery.yaml` and
  `smithery mcp publish` belong to the retired hosting and CLI.
- **No public submission route is documented.** `smithery.ai/new` returns 404.
  Ask Smithery by email (address on [smithery.ai/future](https://www.smithery.ai/future))
  whether Wave CXM can be listed, citing the Official MCP Registry entry
  `com.wavecxm/mcp`.

Suggested copy: the one-liner and long description from the
[shared copy](README.md#shared-copy), with the server URL
`https://api.wavecxm.com/mcp`.

Source: https://www.smithery.ai/future
