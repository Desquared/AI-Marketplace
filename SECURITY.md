# Security Policy

Please **do not** report security vulnerabilities through public GitHub issues,
discussions or pull requests.

Report them privately to **[TO BE COMPLETED: security contact address]**, or
through GitHub's [private vulnerability reporting](../../security/advisories/new)
for this repository.

Include:

- the plugin and version affected;
- the runtime (Claude Code, Copilot CLI, Codex, Cursor or other) and its
  version;
- steps to reproduce, and the impact you observed.

We aim to acknowledge reports within three business days.

Vulnerabilities in a hosted service a plugin connects to, such as the Wave CXM
platform, are in scope here too: report them the same way and we will route
them.
